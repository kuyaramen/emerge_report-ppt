# Serverless Computing Presentation

A web-based interactive presentation on Serverless Computing.

## How to run the presentation

You do NOT need `npm`, `python`, or any complex server to run this presentation. It is built using plain HTML, CSS, and JavaScript.

1. Open this project folder (`EMERGING REPORT`).
2. Double-click `index.html` to open it directly in your web browser (Chrome, Edge, Firefox, etc.).
3. Or use VS Code Live Server if you prefer a local development server.
4. Use the **Next** and **Previous** buttons at the bottom of the screen.
5. Use **ArrowLeft** and **ArrowRight** on your keyboard to navigate easily.

## Features Included
- Progress bar indicator.
- Keyboard navigation (Arrow keys, Spacebar, Home, End).
- Fullscreen mode.
- Interactive quiz answers (click "Show Answer" to reveal).
- Clean, responsive dark navy theme designed for IT/CS reports.
